### 💡 Навыки

**Анализ и подготовка данных** — разведочный анализ (EDA), очистка данных, обработка пропусков и выбросов, конструирование признаков, кодирование категориальных переменных, работа с датами.

**Статистика** — проверка гипотез: t-тест, критерий Манна — Уитни, ANOVA, Краскела — Уоллиса, хи-квадрат.

**SQL** — JOIN, агрегаты, GROUP BY / HAVING, подзапросы.

**Машинное обучение** — регрессия и классификация, отложенная выборка и кросс-валидация, случайный лес и градиентный бустинг (CatBoost), метрики MAPE, ROC-AUC, precision / recall / F1.
